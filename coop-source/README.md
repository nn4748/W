# CO-OP Accounting Hub

موقع ثابت (HTML + CSS + JavaScript) بدون أي مكتبات أو خطوات بناء.

| الملف | المحتوى |
|---|---|
| `index.html` | هيكل الصفحة والأقسام |
| `style.css` | التصميم: الألوان والخطوط والحركة والوضع الداكن |
| `app.js` | كل التفاعل: البحث، الفلاتر، المتابعة، مولّد الإيميل، وضع التدريب |
| `data.js` | بيانات الجهات `D` وأسئلة المقابلات `Q` — عدّلها لإضافة جهة أو سؤال |
| `assets/` | الشعارات وصورة الروبوت |

## الرفع على Netlify
اسحب المجلد كامل (أو ملف zip له) إلى https://app.netlify.com/drop

## تعديل الألوان
أول المتغيرات في `style.css` تحت `:root` (الوضع الفاتح) و `[data-theme="dark"]` (الداكن).

## إضافة جهة في data.js
`{"n":"اسم الجهة","g":0,"s":"القطاع","c":"المدينة","e":["hr@x.com"],"l":"رابط التقديم","i":"رابط لينكدإن","u":0}`
— `g`: 0 مكاتب محاسبة، 1 بنوك ومالية، 2 هيئات ووزارات، 3 شركات. `u`: 1 = من قائمة وليد.
